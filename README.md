# Python Hypotenuse Calculator

## Description
This program uses the math library to use the math.sqrt feature to use the hypotenuse formula.

## How to run:
The user enters the 2 variables: side a length and side b length and then the final answer is displayed rounded down to 2 decimal places.

## Input Needed:
    -length a 
    -length b

## Sample Output
    Enter the length of side a: 6
    Enter the length of side b: 8
    The hypotenuse is : 10.00
